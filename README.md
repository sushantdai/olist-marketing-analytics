
# Olist Marketing Analytics

An end-to-end analysis of ~100K orders from Olist, a Brazilian e-commerce marketplace (2016–2018), to understand what drives repeat purchases, delivery performance, customer satisfaction, and revenue by category and region. The project moves from SQL (DuckDB) to a Power BI dashboard to a Python rebuild with regression, and every finding is tied to a business recommendation.

**Status:** In progress (Week 1: SQL exploration)

**Data:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle). Raw data is not stored in this repo.
